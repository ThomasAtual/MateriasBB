# Minha Trilha de Estudos

Página estática para acompanhar os assuntos dos sumários dos 95 PDFs contidos no `GRAN.zip`. As matérias, os PDFs e os tópicos seguem a ordem em que aparecem no arquivo ZIP. Os PDFs não estão incluídos no site; a página organiza os estudos a partir dos sumários.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie todos os arquivos desta pasta para a raiz do repositório.
2. Abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)`, e salve.
4. Abra o endereço publicado no Safari do iPhone e toque em **Compartilhar → Adicionar à Tela de Início**.

## Uso e dados

Escolha uma matéria. Cada PDF aparece na ordem do pacote; toque no título para expandir seu sumário. Cada tópico tem uma caixa de conclusão e um campo para comentário. Use a busca para localizar um PDF ou assunto. O tema claro/escuro, progresso e comentários ficam salvos no `localStorage` do navegador em uso; não há conta nem sincronização entre aparelhos. Evite limpar os dados do site para preservar seu progresso.
